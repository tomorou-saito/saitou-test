# しまのてちょう

『あつまれ どうぶつの森』の住民を記録する日本語の非公式Webアプリです。HTML・CSS・JavaScriptのみで動きます。ビルドやAPIキーは不要です。

## 使い方

1. フォルダを展開し、`index.html`をChrome / Edge / Firefox / Safariなどの現行ブラウザで開きます。
2. 名前・種族・性格で住民を検索します。名前はひらがな・カタカナ・英語、全角・半角に対応します。
3. 「＋ 島の仲間にする」で最大10名まで登録できます。登録後のボタンや上部の×で外せます。
4. ♡で欲しい住民を登録できます。島の仲間とは独立したリストです。
5. 「抽選のしくみを読む」で性格の偏りと、現在の島構成に応じた参考モデルを確認できます。
6. 「記録を書き出す」でバックアップを保存します。別端末では「記録を読み込む」で引き継げます。読み込み前に置き換え確認があります。

登録は各利用者のブラウザに自動保存されます。アカウント登録やサーバー送信はありません。ブラウザの保存領域の削除・プライベートモード終了などで消えることがあるため、バックアップをご利用ください。ファイル直接起動の保存動作はブラウザ依存です。継続利用にはGitHub Pagesなど固定URLでの利用を推奨します。直接起動と公開URLの記録は別々なので、公開先へはバックアップを読み込んでください。

## GitHub Pagesで公開する

まだGitHubへのアップロードや公開は行っていません。公開するときは次の手順で進められます。

1. GitHubでリポジトリを作成します。
2. このフォルダの**中身**をリポジトリ直下にアップロードします。`index.html`、`style.css`、`app.js`、`data.js`、`assets/`、出典文書を含めてください。
3. リポジトリの **Settings → Pages → Build and deployment** を開き、**Deploy from a branch** を選びます。
4. アップロード先のブランチ（通常`main`）、フォルダ`/ (root)`を選んで保存します。
5. GitHubに表示される公開URLからアクセスします。

画像も同じフォルダから読み込むため、リポジトリ名が付くURLでも動作します。ビルド設定は不要です。バックアップJSONは個人用のためリポジトリにアップロードしないでください。

公式手順：https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

## データ範囲・モデルの制限

2026年11月5日確認。通常住民407名・サンリオ6名・Ver.3.0コラボ4名、合計417名です。施設スタッフなどの特別キャラクターは対象外です。Ver.3.0の4名の画像は未収録のため種族の絵文字を表示します。名前・性格・種族・誕生日のデータと登録機能は利用できます。

性格の人数グラフは島の人数であり、確率ではありません。詳細画面の確率はコミュニティWikiを参考にした仮定のモデルです。任天堂の公式確率ではなく、過去の訪問・居住・移住待ちなどの履歴を扱っていません。現行版での厳密なゲーム内部仕様を保証しません。

サンリオ・Ver.3.0コラボ住民は自然訪問の候補から除外します。島に登録した場合は性格構成に数えます。欲しい住民への登録だけでは島の性格構成は変わりません。

本ツールは任天堂の公式サービスではありません。データと画像の出典・利用条件は`SOURCES.md`を参照してください。第三者のデータ・画像にアプリ独自のライセンスを適用していません。
